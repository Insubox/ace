LINUX X86-64 PREVIEW + MAC INTEL BETA

Run your first ACE experiment.

The native CLI demo runs offline. It needs no account, API key, Cloudflare service, Node or Docker. ACE preserves source and learning in its own version engine; Git is optional for compatibility.

No account is needed for the Linux or Mac Intel demo. Choose the package matching your computer below. Source access and complete application campaigns still require access to the private GitHub repository. Windows and Mac Apple silicon betas are in preparation; native testing is pending.

2. Verify and extract

On Linux, open a terminal in the download folder:

sha256sum -c ace-0.4.0-x86_64-unknown-linux-musl.tar.gz.sha256
tar -xzf ace-0.4.0-x86_64-unknown-linux-musl.tar.gz
cd ace-0.4.0-x86_64-unknown-linux-musl

On Mac Intel, open Terminal in the download folder:

shasum -a 256 -c ace-0.4.0-x86_64-apple-darwin.tar.gz.sha256
tar -xzf ace-0.4.0-x86_64-apple-darwin.tar.gz
cd ace-0.4.0-x86_64-apple-darwin

The checksum check should report OK. The package contains ace, GETTING_STARTED.md and THIRD_PARTY_NOTICES.txt and BUILD.json, which records the source commit and executable hash.

3. Run the offline demo

./ace --version
./ace demo
./ace status ace-demo/run
./ace knowledge ace-demo/run
./ace inspect ace-demo/run --output report.html

Expect 13 programs: a baseline and 12 candidates. Ten qualify; three deliberate diagnostic controls exercise incorrect code, fuel exhaustion and memory limits. ACE retains the inputs, source, results and champion in ace-demo. The terminal prints the command to replay the champion independently. Open report.html to inspect the exported evidence.

4. Keep improving across generations

./ace evolve ace-evolution --generations 3 --json
./ace history ace-evolution

Generations preserve linked evidence and previous champions. MCP integration exposes 30 local tools for proposals, execution, native source history and collaboration. Consult the packaged guide or repository documentation for agent campaigns, replay, clone and checkout.

Native packages for Windows and Mac Apple silicon still require execution on those platforms. Developers with repository access can use the native build and verification guide. No GitHub Actions minutes or provider account is needed for local validation.

Work with complete applications

Hello World, TicTacToe and Calculator compile and test as complete projects under protected dependencies and suites. These campaigns require repository access, Rust, Node and Docker. They are separate from the standalone binary demo.

git clone https://github.com/Insubox/ace.git
cd ace
cargo build --locked -p ace-cli
docker build -f applications/Dockerfile -t ace-applications:local .
node scripts/check-application-tasks.mjs --output /tmp/ace-task-check

The controlled examples repair Hello World from 4/11 to 11/11, TicTacToe from 19/20 to 20/20 and Calculator from 28/29 to 29/29. They retain rejected proposals and generator faults. The learning comparison tests compatible retrieved evidence with a curated repair policy; it does not establish general model performance.
