# tictactoe

This project has a shared JavaScript core, a Node CLI and a browser UI.
Install the exact external dependency with `npm ci`.
Run `npm start` with one JSON request on stdin.
From the ACE repository, run `node applications/serve.mjs /absolute/path/to/project` and open the printed URL.
Run `ace app test . --image ace-applications:local --output ../result --store ../history`.
See ace-app.json, dependencies.lock.json and package-lock.json for pinned dependencies.
